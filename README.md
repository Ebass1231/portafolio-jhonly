# Portafolio de Jhonly Santos

Sitio estático listo para publicación. No requiere base de datos, WordPress, Wix ni servidor de pago.

## Publicación recomendada: GitHub Pages

1. Crea una cuenta gratuita en GitHub.
2. Crea un repositorio público llamado `portafolio-jhonly`.
3. Sube todo el contenido de esta carpeta, manteniendo la carpeta `assets`.
4. En el repositorio abre `Settings > Pages`.
5. En `Build and deployment`, selecciona `Deploy from a branch`.
6. Selecciona la rama `main`, carpeta `/root` y pulsa `Save`.
7. GitHub mostrará una dirección similar a `https://tuusuario.github.io/portafolio-jhonly/`.

## Alternativa sencilla: Cloudflare Pages

1. Crea una cuenta gratuita en Cloudflare.
2. Abre `Workers & Pages > Create application > Pages > Direct Upload`.
3. Crea el proyecto y arrastra esta carpeta o el ZIP.
4. Cloudflare publicará el sitio con una dirección `pages.dev`.

## Personalización

- Textos y enlaces: edita `index.html`.
- Videos: edita la lista `videos` dentro de `script.js`.
- Colores y diseño: edita las variables al inicio de `styles.css`.
- Fotografía: reemplaza `assets/jhonly-santos.png` conservando el nombre.

## Wix

Wix no importa de forma nativa un sitio HTML completo como páginas editables. Puedes reproducir este diseño con Wix Studio o insertar partes mediante un elemento de código embebido, pero para conservar exactamente el diseño y las animaciones conviene publicarlo como sitio estático en GitHub Pages o Cloudflare Pages.
